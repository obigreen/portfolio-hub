# Portfolio Hub

Монорепозиторий законченных веб-проектов: лендингов, многостраничных
сайтов, небольших приложений и WordPress-решений.

## Быстрый запуск

Каркас не требует установки зависимостей:

```bash
python3 -m http.server 8080
```

После запуска открой:

```text
http://localhost:8080
```

## Как добавить карточку

Добавь объект в:

```text
assets/js/projects-data.js
```

Основные поля:

- `category` — физический тип проекта;
- `type` — короткая подпись формата проекта;
- `description` — одно небольшое пояснение;
- `stack` — технологии и инструменты;
- `demoUrl` — ссылка, которую откроет кнопка проекта.

## Структура проектов

```text
projects/
├── landings/
├── multipage/
├── applications/
└── fullstack/
```

Каждый проект хранит собственные исходники, зависимости, документацию
и инструкции по запуску. WordPress-проекты публикуются без секретов,
production-базы, `wp-config.php` и пользовательских загрузок.
