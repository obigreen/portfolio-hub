# Portfolio Hub

> Единое пространство для хранения, организации и демонстрации завершённых веб-проектов.

Portfolio Hub объединяет независимые проекты в одном репозитории и предоставляет простой каталог для быстрого перехода к каждому из них. Хаб не заменяет основное портфолио — он служит технической точкой входа и помогает поддерживать проекты в структурированном виде.

## Категории

- **Landings** — одностраничные сайты и промостраницы
- **Multipage** — многостраничные сайты
- **Applications** — клиентские веб-приложения
- **Fullstack** — проекты с frontend- и backend-частями

## Структура

Каждый проект хранится в собственной директории и может содержать:

- автономную статическую версию;
- исходный код и ресурсы;
- CMS-тему и пользовательские плагины;
- ссылку на локальное демо или опубликованную версию.

## Навигация

Проекты выводятся из единого массива данных и фильтруются по категориям. Для каждого проекта указывается один вариант открытия:

- `demoUrl` — версия внутри Portfolio Hub;
- `liveUrl` — опубликованная версия проекта.

## Технологии хаба

`HTML5` · `CSS3` · `Vanilla JavaScript`
