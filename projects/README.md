# Projects

В этой директории находятся изолированные исходники проектов.

- `landings/` — одностраничные сайты и их WordPress-версии;
- `multipage/` — многостраничные сайты;
- `applications/` — frontend-приложения;
- `fullstack/` — проекты с отдельными frontend и backend частями.

Технологии проекта указываются тегами в его `README.md` и в данных
каталога, а не используются как основной уровень вложенности.
